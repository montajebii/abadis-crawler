# Contributing

## چطور داده جمع کنم؟

1. اسکریپت را طبق `docs/SETUP_TERMUX.md` نصب کنید.
2. یک `DEVICE_ID` یکتا در `.env` بگذارید (مثلاً با `uuidgen`).
3. اجرا کنید: `python -m crawler --max-words 500`
4. فایل CSV تولیدشده را به `data/raw/<DEVICE_ID>_<timestamp>.csv` کپی کنید.
5. یک Pull Request به مخزن باز کنید.

ورک‌فلوی `validate-pr.yml` به‌طور خودکار CSV را بررسی می‌کند؛ اگر خطا داشت،
پیام دقیق در PR نمایش داده می‌شود.

## چطور کد مشارکت کنم؟

- تست‌های جدید بنویسید (`pytest`).
- برای تغییرات بزرگ، ابتدا یک Issue باز کنید.
- کد با `ruff check` و `ruff format` تمیز باشد.

## نکات مهم

- `data/raw/` را دستی ویرایش نکنید؛ فقط از اسکریپت خزنده استفاده کنید.
- هرگز `.env` یا `*.db` را کامیت نکنید (در `.gitignore` هستند).
- درخواست‌ها باید با احترام به سرور آبادیس ارسال شوند (AIMD و تأخیر تصادفی).
